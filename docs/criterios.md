# Criterios de clasificación

Los recursos académicos se clasificarán utilizando al menos los siguientes criterios:

1. **Tipo**: libro, sitio web, video, artículo, herramienta de software.
2. **Tema**: área o disciplina a la que pertenece el recurso (ej. matemáticas, programación, historia).
3. **Nivel**: básico, intermedio, avanzado.
4. **Autor o fuente**: persona, institución u organización responsable del contenido.
