# Alcance del proyecto

Una versión futura del sistema podría incluir las siguientes funcionalidades:

1. **Registro de recursos**: permitir agregar nuevos recursos académicos (libros, artículos, videos, etc.) con sus metadatos correspondientes.
2. **Búsqueda y filtrado**: consultar recursos por tipo, tema, nivel o autor mediante filtros combinables.
3. **Sistema de recomendaciones**: sugerir recursos relacionados con base en el historial de consultas del usuario.
4. **Exportación de catálogos**: generar listas o reportes en formatos como PDF o CSV para compartir con otros usuarios.
5. **Integración con APIs externas**: conectar con bibliotecas digitales o repositorios académicos para importar recursos automáticamente.
